  ★ Insight ─────────────────────────────────────                                                                                                                                                                                                                                                                             
  Why the 'c' is eaten on Windows: The reuse-terminal path sends the command via PTY write only ~5-20ms after the Ctrl+Shift+Enter keydown (just IPC round-trip time). On Windows, ConPTY translates raw pipe bytes into Win32 console input records. If the physical Ctrl key is still held when the first byte 'c' (0x63)   
  reaches ConPTY, it can be interpreted as Ctrl+C (0x03) — a control character the shell swallows silently. The remaining bytes 'laude...' arrive after Ctrl is released and are processed normally.                                                                                                                          
                                                                                                                                                                                                                                                                                                                              
  Why the new-terminal path doesn't have this issue: It waits for TERMINAL_SHELL_READY (typically 1+ seconds for PowerShell profile loading) or a 3-second fallback — both far longer than any human key hold time.                                                                                                           
                                                                                                                                                                                                                                                                                                                              
  The 80ms delay: Chosen because it's well above the typical key-release time (~30-60ms after the triggering key) while being imperceptible to the user. The delay only applies to the reuse path — new terminals already have sufficient delay from shell-ready detection.
