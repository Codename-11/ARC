  ★ Insight ─────────────────────────────────────
  - cmd /c pnpm build avoids Node 24's new DEP0190 deprecation warning. On Windows, pnpm is a .cmd file 
  that requires shell resolution — using cmd /c delegates that to the shell without passing
  user-controlled args through shell: true.
  - Install metadata (~/.local/bin/.arc-install.json) tracks whether the installer added the PATH entry,
   so uninstall can cleanly reverse only what it changed.
  - The shim approach (vs pnpm link --global) is more robust for local dev — it survives pnpm install,  
  doesn't pollute the global package list, and the shims always point at your working copy's
  dist/index.js.
